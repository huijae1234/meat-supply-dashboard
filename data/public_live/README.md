# 공개 공공데이터 기본본

공개 체험판이 처음 열릴 때 보여 주는 기본 자료입니다. 축산물품질평가원 유통정보·경락가격 API의 공개 응답과 한국수출입은행 환율 API의 공개 응답을 CSV로 정리했습니다. 인증키, 회사 CSV, 사용자 입력 및 수집 오류 기록은 포함하지 않습니다.

| 파일 | 내용 | 기본본의 마지막 날짜 |
|---|---|---|
| `stock.csv` | 축종·부위별 월 재고 | 2026-07-01 |
| `price_daily.csv` | 일별 소비자가격 | 2026-10-12 |
| `price_month.csv` | 월별 소비자가격과 평년가격 | 2026-10-01 |
| `auction_beef.csv` | 소 경락가격 | 2026-10-07 |
| `auction_pig.csv` | 제주 돼지 경락가격 | 2026-10-07 |
| `fx.csv` | 한국수출입은행 환율 | 2026-10-16 |

출처: [축산물품질평가원 축산물유통정보](https://www.data.go.kr/data/15000577/openapi.do), [한국수출입은행 환율 정보](https://www.data.go.kr/data/3068846/openapi.do). 각 지표의 발표·갱신 시차가 다르므로 이 기본본을 현재 공장 재고나 실시간 거래가격으로 해석하지 마세요. 공개 서버에 비공개 API 키가 설정되어 있으면 서버가 제한된 횟수로 최신 자료를 확인합니다.
