# 디자인 원칙

이 대시보드는 즐기는 곳이 아니라 **정보를 확인하는 도구**다. 그래서 색과 장식을 최소로 쓰고, 색을 쓸 때는 반드시 뜻이 있게 한다.
토큰과 스타일은 [`lib/theme.py`](../lib/theme.py) 한 곳에 있다.

## 색

| 역할 | 값 | 쓰임 |
|---|---|---|
| 페이지 / 카드 | `#f9f9f7` / `#fcfcfb` | 바탕은 중립 회색 톤, 카드는 한 톤 위 |
| 글자 | `#1a1a19`, 보조 `#52514e` | 본문은 짙게, 설명은 보조색(대비 7:1 이상) |
| 격자·테두리 | `#e1e0d9` | 실선 한 가닥. 점선·굵은 선 없음 |
| 눈금 글자 | `#898781` | 차트 축 눈금에만. 본문 글자에는 쓰지 않음 |
| 강조 | `#1c5cab` (선택한 화면·링크), 차트 기본 계열 `#2a78d6` | **파랑 한 가지** |
| 예측·두 번째 계열 | `#eb6834` | 파일 예측, 두 번째 계열에만 |
| 상태 | 좋음 `#0ca30c` · 주의 `#fab219` · 발주 `#ec835a` · 긴급 `#d03b3b` | **상태를 뜻할 때만.** 항상 작은 점 + 글자 라벨(색만으로 말하지 않음) |

- 차트 계열 색은 검증된 고정 순서(파랑, 주황, 아쿠아, 노랑, 분홍, 초록)이고 **순환하지 않는다.** 같은 나라는 어느 차트에서나 같은 색이다. '기타'(묶음)는 회색.
- 값의 부호는 **양수 = 빨강, 음수 = 파랑**으로 통일한다(초록·빨강 쌍은 색약에서 구분이 어렵다).
- 검증: `node scripts/validate_palette.js "#2a78d6,#eb6834,#1baf7a,#eda100,#e87ba4,#008300" --mode light --surface "#fcfcfb"` → 전 항목 통과
  (아쿠아·노랑·분홍은 흰 바탕 대비 3:1 미만이라 범례를 항상 둔다).

## 레이아웃
- **왼쪽 내비게이션**은 화면 이동만 맡고 4개 그룹(오늘 / 우리 공장 / 실제 데이터 / 시연(합성 데이터))으로 나눈다. 화면마다 주소가 있다(`/today`, `/company`, `/live`, `/analysis`, `/demo-*`).
- **위쪽**에는 자주 바꾸는 육종(돼지/소)만 보이게 두고, 거의 안 바꾸는 값(경보 민감도, 기준선, 데이터 다시 읽기)은 `설정` 팝오버 안에 모은다. 설정을 상단에 펼쳐 두지 않는다.
- 한 번에 한 화면만 실행하므로 예전 탭 방식(11개 탭을 전부 실행)보다 응답이 가볍다.

## 모양
- 카드·차트·표는 **그림자 없이 1px 테두리**, 모서리 8px.
- 제목은 굵기를 낮추고(헤더 700, 소제목 700, 나머지 500), 장식 이모지와 채워진 색 상자를 쓰지 않는다. (제목의 🥩🐷🐂만 예외)
- 안내 상자는 색칠하지 않고 중립 바탕 + 왼쪽 가는 막대.
- 신호등 이모지(🔴🟠🟢) 대신 **점 + 글자**(`theme.dot`, `theme.kpi_html`).
- 숫자는 비례 폭 숫자, 정렬이 필요한 표에서만 `tabular-nums`.

## 차트
- 면 채우기는 중립 회색 위주(정상 범위 `rgba(11,11,11,.05)`, 예측 구간 `rgba(11,11,11,.04)`).
- 격자는 가로선만 실선 헤어라인, 세로 격자 없음. 축선은 한 단계 진한 회색.
- 제목은 왼쪽 정렬, 범례는 위쪽에 가로로. 계열이 2개 이상이면 범례를 항상 둔다.
- 색 대비가 낮은 계열은 범례와 표(데이터프레임)로 값을 읽을 수 있게 둔다.

## 하지 않은 것
- 다크 모드: 라이트 모드 기준이다.
- 차트 툴팁·키보드 접근성 개선: Plotly 기본 동작을 그대로 쓴다.
