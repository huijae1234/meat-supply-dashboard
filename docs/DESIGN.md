# 디자인 원칙

이 대시보드는 즐기는 곳이 아니라 **정보를 확인하는 도구**다. 그래서 장식은 아끼고, 색은 **화면 구조**(어디가 메뉴·제목·카드인지)와 **상태**(긴급·발주·넉넉함·정상)를 알려 주는 데 쓴다.
포트폴리오로 보여 주는 점을 고려해 메인 색 그라데이션을 **포인트에만** 넣었다. 표와 글자 영역은 흰 바탕으로 깔끔하게 둔다.
토큰과 스타일은 [`lib/theme.py`](../lib/theme.py) 한 곳에 있고, Streamlit 기본 색(위젯·사이드바 글자)은 [`.streamlit/config.toml`](../.streamlit/config.toml)에서 같은 값으로 맞춘다.

## 색

메인 색은 **짙은 네이비 → 딥 청록**이다. 시안 4종(네이비·와인·포레스트·인디고)을 실제 화면에 입혀 비교한 뒤 골랐고, 처음 시안보다 한 단계 어둡게 조정했다.
상태색(빨강·주황·노랑·초록)과 겹치지 않아 '긴급'이 메인 색에 묻히지 않는다.

| 역할 | 값 | 쓰임 |
|---|---|---|
| 메인 그라데이션 | `#19324f` → `#0b8783` | 상단 헤더 띠, 화면 제목 글자, 소제목 막대, 카드 위쪽 띠, 버튼 hover, 탭 밑줄 |
| 사이드바 | `#162b47` → `#0b3e4a` (세로) | 왼쪽 메뉴 바탕. 글자 흰색, 선택한 화면은 밝은 막대 `#4fd6c2` |
| 강조 | `#1f54d4` | 위젯 선택·포커스·링크 (config `primaryColor`) |
| 연한 바탕 | `#e7eef8` | 정보 안내 상자, 펼침 상자 hover |
| 페이지 / 카드 | `#f1f4f8` / `#ffffff` | 바탕은 연한 푸른 회색, 카드·차트·표는 흰색 |
| 글자 | `#18212e`, 보조 `#475365` | 본문은 짙게, 설명은 보조색(대비 7:1 이상) |
| 격자·테두리 | `#dde3eb`, 축선 `#c1c9d5` | 실선 한 가닥 |
| 눈금 글자 | `#808da0` | 차트 축 눈금에만. 본문 글자에는 쓰지 않음 |
| 차트 첫 계열 | `#2158d4` | 실적·주요 값 |
| 예측·두 번째 계열 | `#eb6834` | 파일 예측, 두 번째 계열 |
| 상태 | 좋음 `#0ca30c` · 주의 `#fab219` · 발주 `#ec835a` · 긴급 `#d03b3b` | **상태를 뜻할 때만.** 항상 작은 점 + 글자 라벨(색만으로 말하지 않음). 카드에서는 위쪽 띠도 상태색 |

- 차트 계열 색은 고정 순서(파랑, 주황, 아쿠아, 노랑, 분홍, 초록)이고 **순환하지 않는다.** 같은 나라·원료는 어느 차트에서나 같은 색이다. '기타'(묶음)는 회색.
- 값의 부호는 **양수 = 빨강, 음수 = 파랑**으로 통일한다(초록·빨강 쌍은 색약에서 구분이 어렵다).
- 검증(dataviz 팔레트 검증 스크립트): `node validate_palette.js "#2158d4,#eb6834,#1baf7a,#eda100,#e87ba4,#008300" --mode light --surface "#ffffff"` → 전 항목 통과
  (색약 구분 최소 ΔE 9.1, 일반 시력 최소 ΔE 19.6. 아쿠아·노랑·분홍은 흰 바탕 대비 3:1 미만이라 범례·표를 항상 함께 둔다).

## 그라데이션을 넣은 곳 (포인트에만)

| 위치 | 모양 |
|---|---|
| 상단 헤더 | 둥근 띠에 메인 그라데이션, 흰 제목, 수집 상태는 반투명 알약 모양 |
| 왼쪽 메뉴 | 세로 그라데이션 + 흰 글자, 선택한 화면은 옅은 가로 그라데이션 + 왼쪽 밝은 막대 |
| 화면 제목 | 글자 자체에 메인 그라데이션 |
| 소제목(####) | 앞에 작은 세로 그라데이션 막대 |
| 카드 | 흰 카드 위쪽에 3px 띠(중립 카드는 메인 그라데이션, 상태 카드는 상태색) |
| 버튼 | 평소엔 흰 바탕, 마우스를 올리면 메인 그라데이션 |
| 추이 차트 | 실적선 아래 옅은 세로 그라데이션(`theme.soft_area`). 축이 0까지 늘어나지 않도록 최솟값 바로 아래까지만 채운다 |

표, 긴 글, 입력칸, 막대그래프에는 그라데이션을 넣지 않는다.

## 레이아웃
- **왼쪽 내비게이션**은 화면 이동만 맡고 3개 그룹(생산관리 / 시장 참고 / 분석 과정(합성·보조))으로 나눈다. 화면마다 주소가 있다(`/today`, `/company`, `/thaw`, `/expiry`, `/cost`, `/planning`, `/orders`, `/worklog`, `/live`, `/analysis`, `/fx`, `/demo-*`).
- 거의 안 바꾸는 값(육종, 경보 민감도, 기준선, 데이터 다시 읽기)은 오른쪽 위 `설정` 팝오버 안에 모은다. 설정을 상단에 펼쳐 두지 않는다.
- 한 번에 한 화면만 실행하므로 응답이 가볍다.

## 모양
- 카드·차트·표는 1px 테두리 + 아주 옅은 그림자, 모서리 10~12px.
- 숫자 값은 굵게(800), 소제목 700, 나머지 500. 장식 이모지는 쓰지 않는다(제목의 🥩🐷🐂만 예외).
- 안내 상자는 연한 색 바탕 + 왼쪽 막대: 정보는 메인 색, 성공·주의·오류는 상태색.
- 신호등 이모지(🔴🟠🟢) 대신 **점 + 글자**(`theme.dot`, `theme.kpi_html`).
- 숫자는 비례 폭 숫자, 정렬이 필요한 표에서만 `tabular-nums`.

## 차트
- 면 채우기는 중립 회색 위주(정상 범위 `rgba(11,11,11,.05)`, 예측 구간은 메인 색 5%). 주요 추이선 아래만 메인 색 옅은 그라데이션.
- 격자는 가로선만 실선 헤어라인, 세로 격자 없음. 축선은 한 단계 진한 회색.
- 제목은 왼쪽 정렬, 범례는 위쪽에 가로로. 계열이 2개 이상이면 범례를 항상 둔다.
- 색 대비가 낮은 계열은 범례와 표(데이터프레임)로 값을 읽을 수 있게 둔다.

## 하지 않은 것
- 다크 모드: 라이트 모드 기준이다.
- 배경 그림·일러스트·장식 아이콘: 색감만으로 꾸민다.
- 차트 툴팁·키보드 접근성 개선: Plotly 기본 동작을 그대로 쓴다.
