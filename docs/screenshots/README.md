# 화면 이미지 안내

[프로젝트 소개로 돌아가기](../../README.md)

2026년 10월 14~15일 실제 브라우저 화면을 촬영한 JPEG 이미지입니다. 화면을 따로 그린 목업이 아닙니다.

로컬 Streamlit 앱에서 촬영했습니다. 오늘의 현황은 내장 공장 샘플(가짜) 데이터와 이미 수집된 공공 시장 데이터를 보여 줍니다. 예측 화면은 합성 데이터 시연입니다. 실제 회사 파일은 사용하지 않았고, 새로운 API 수집도 실행하지 않았습니다.

이미지의 숫자와 날짜는 촬영 당시의 예시 상태입니다. README는 저장소 내부의 상대 경로로 이미지를 불러옵니다.
