# 화면 이미지 안내

[프로젝트 소개로 돌아가기](../../README.md)

2026년 10월 18일 로컬 Streamlit 앱을 1280×720 크기로 실제 실행해 촬영한 JPEG 이미지입니다(Edge를 화면 없이 실행해 캡처, 네이비·청록 색 적용 후). 화면을 따로 그린 목업이 아닙니다.

- `01-today.jpg` — `오늘의 생산 위험`. 내장 공장 샘플(가짜) 데이터의 원료 기준 생산 가능량·부족량과 영향받는 생산계획입니다. 시장 참고 정보는 이미 수집된 공공데이터입니다.
- `02-forecast.jpg` — `수급 추이·예측`. 합성 데이터로 분석 방법을 보여 주는 시연 화면입니다.

실제 회사 파일은 사용하지 않았고, 촬영을 위해 새로운 API 수집도 실행하지 않았습니다. 이미지의 숫자와 날짜는 촬영 당시의 예시 상태이며, 샘플 날짜는 실행일 기준으로 만들어지므로 다시 실행하면 달라집니다. README는 저장소 내부의 상대 경로로 이미지를 불러옵니다.
