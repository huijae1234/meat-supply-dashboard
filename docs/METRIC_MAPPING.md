# 합성 지표 ↔ 실제 데이터 대응표 (Phase 3)

범례: ✅ 실제 데이터로 대응(연동 완료) · 🔶 후보 있음(미연동/미검증) · ❌ 대응 없음

## fact_supply_weekly (주간 전국 수급)
| 합성 컬럼 | 실제 대응 | 비고 |
|---|---|---|
| `ending_stock_kg` 기말 재고 | ✅ LPStock (부위별 월 재고) | **월 단위, 약 2~3개월 지연.** 돼지 톤→kg 환산. 합성은 주간·모델 가정치 |
| `slaughter_heads` 도축 두수 | ❌ | API 미확인 (docs/API_SURVEY.md) |
| `domestic_output_kg` 국내 생산 | ❌ | 도축 두수에서 환산하는 합성 값. 실제 대응 없음 |
| `import_volume_kg` 수입량 | 🔶 관세청 신성질별 국가별 수출입실적 | 월 단위, 미검증 |
| `import_share_pct` 수입 비중 | 🔶 | 수입량과 국내 생산이 모두 있어야 계산 가능 |

## fact_meat_weekly (주 × 지역 × 부위 × 채널 × 원산지)
| 합성 컬럼 | 실제 대응 | 비고 |
|---|---|---|
| `retail_price_krw_kg` | ✅ consumerPriceDaily/Month | 일별, 부위·등급별, 평년가격 포함 |
| `wholesale_price_krw_kg` | ✅ 소 / 🔶 돼지 | 소: 전 도매시장 평균 경락가. 돼지: **제주 지역만** |
| `cut_id` 부위 | ✅ | 부위 체계가 달라 직접 매핑 불가 (삼겹살·목살 등 공통 일부) |
| `origin` 국산/수입 | ✅ | 품종 코드(4301/4304 vs 4401/4402)로 구분 |
| `region_id` 지역 | 🔶 | 응답에 지역별 가격 `regionPrc1~17` 있음, 코드 정의 확인 필요 |
| `channel_id` 채널 | ❌ | |
| `consumption_kg`, `sales_krw` 소비량·판매액 | ❌ | 실제 소비량 API 미확인 |

## 대시보드 탭 단위 요약
| 탭 | 데이터 | 이유 |
|---|---|---|
| ① 현황·경보 | 합성 | 실제 대응: ⑧ KPI·재고 경보, ⑨ 재고·가격 경보 |
| ② 수급 추이·예측 | 합성 | 실제 대응: ⑨ 월 재고·일 가격 예측 |
| ③ 계절성·이상치 | 합성 | 도축·생산 주간 데이터 없음 |
| ④ 명절·이벤트 | 합성 | 소비량 데이터 없음 |
| ⑤ 수입국·단가 | 합성 | 관세청 API 신청·검증 필요 |
| ⑥ 가격·소비 | 합성 | 실제 대응: ⑧ 소비자가·경락가·국산 vs 수입, ⑨ 시차 분석. 소비량은 없음 |
| ⑦ 유통 병목 | 합성 | 공개 데이터 없음 |
| ⑧ 실제 데이터 | **실제** | 축산물품질평가원 API |
| ⑨ 실제 분석·예측 | **실제** | ⑧ 저장 데이터 기반 |
