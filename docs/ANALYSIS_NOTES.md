# 분석 노트 — 축산물(돼지·소) 수급 모니터링

작성 2026-10-08. 수치는 저장된 실제 데이터와 코드 실행 결과에서 가져왔다.

## 1. 질문
생산·재고 관리자의 관점에서 다음을 알고 싶었다.
1. 재고가 부족/과잉으로 가고 있는가? (조기 경보)
2. 가격은 평소(평년)에 비해 어떤가, 도매(경락가)가 소매(소비자가)로 얼마나 빨리 전달되는가?
3. 앞으로 재고·가격을 얼마나 믿을 만하게 예측할 수 있는가?
4. 수입 의존도·명절·유통 병목은 어떤가? (합성 데이터로 설계 검증)

## 2. 데이터
| 구분 | 내용 | 한계 |
|---|---|---|
| 합성 CSV (탭 ①~⑦) | 주간 × 축종 × 지역·부위·채널, 2024-01 ~ 2026-12 (예측 13주 포함) | 모델 가정치. 실제 값이 아님. 소비량 입력 오류 80건 포함(보정함) |
| 실제 API (탭 ⑧~⑨) | 축산물품질평가원: 부위별 월 재고, 일별 소비자가, 월 평년가격, 소 경락가, 제주 돼지 경락가 | 재고는 월 단위·2~3개월 지연(2024-01~2026-07, 31개월). 일별 가격은 2026-04-22부터. 돼지 경락가는 제주만 |
| 제외 | 이력정보 API(개체 단건 조회), AT 최근일자(축산물 7건·2019~2022) | |

합성과 실제는 규모가 다르다(돼지 재고: 실제 약 1.8만 톤, 합성 약 9.2만 톤). 그래서 섞지 않고 탭을 분리했다.

## 3. 방법
- **데이터 수집**: 하루 900건 한도 안에서 최신 날짜부터, 이미 받은 날짜는 건너뜀, 키·권한 오류 시 즉시 중단. 수집 직후 품질 점검(가격 급변, 결측, 단위).
- **재고 경보**: 월 재고에 추세 + 연 1주기 계절을 최소제곱으로 맞추고 잔차 z-score로 판단. 부위별은 자기 이력 대비 z.
- **가격 경보**: 부위별 월평균 소비자가 ÷ 평년가격, 4주 연속 상승/하락.
- **예측**: 모델 5종(직전값, 이동평균, 감쇠 추세 ETS, 추세+계절 릿지, 전년 동기)을 롤링 백테스트로 비교하고 가장 오차가 작은 것을 사용.
- **시차 분석**: 경락가 주간 변화율과 소비자가 변화율의 시차 상관(0~6주), 재고→가격 월 상관. 표본 수와 p값 병기.
- **알림**: 신규 경보만 Windows 알림·로그·대시보드 이력으로 기록(중복 방지).

## 4. 결과 (실제 데이터, 2026-10-08 기준)
### 재고 (마지막 집계 2026-07)
| 축종 | 재고 | z | 신호 | 부위별 이상 |
|---|---|---|---|---|
| 돼지 | 약 1.79만 톤 | +1.39 | 정상(과잉 근접, 임계 ±1.5) | 등심 과잉(z +3.1, 전월 +11%), 전지 과잉(z +2.9) |
| 소 | 약 6.3천 톤 | −2.24 | **부족** | 채끝(z −3.0, 전월 −17%), 목심(z −2.7) 등 다수 부족 |

소 재고는 2026-01 약 9.7천 톤에서 7월 약 6.3천 톤으로 6개월 동안 약 35% 줄었다.

### 가격 (평년 대비 +15% 이상 8개 부위 / 전체 15개)
수입 소고기 갈비살(냉장)·양지(냉장) 각 +27%, 돼지 앞다리 +19%, 한우 설도 +19%, 한우 안심 +18%, 한우 등심 +16%(4주 연속 상승). 돼지 삼겹살은 +12%.

### 예측 정확도 (롤링 백테스트 MAPE)
| 대상 | 가장 좋은 모델 | 직전값 대비 개선 |
|---|---|---|
| 돼지 월 재고(3개월) | 직전값 5.2% (ETS 5.4%, 릿지 8.3%, 전년 동기 10.0%) | 0% |
| 소 월 재고(3개월) | 직전값 10.6% (이동평균 14.1%, ETS 14.6%, 릿지 19.2%) | 0% |
| 삼겹살 일별 소비자가(10영업일) | 직전값 | 0% |
| 한우 등심 일별 소비자가(10영업일) | 감쇠 추세 ETS 1.24% (직전값 1.35%) | 8.6% |

**핵심 결론: 재고는 "현 수준 유지"보다 나은 예측을 만들지 못했다.** 31개월로는 계절성을 안정적으로 학습하기 어렵다. 예측은 보조 지표로만 쓴다.

### 시차·상관
- 경락가→소비자가 주간 변화율 상관은 거의 모든 시차에서 유의하지 않았다(돼지 제주 경락가→삼겹살, 표본 n=18~24주). 소 등심에서 6주 시차 r=0.46(p=0.05, n=18)이 경계적이나 7개 시차를 동시에 검정해 우연일 수 있다. **뚜렷한 전달 시차는 확인하지 못했다.**
- 돼지 재고 변화율→1개월 뒤 삼겹살 가격 r=0.86(p=0.01)로 나왔으나 표본이 8개월이다. 4개 시차를 검정했고 표본이 매우 작아 **가설 수준**이다.

### 합성 데이터 탭에서 검증한 것 (설계 확인용, 실제 결과 아님)
- 합성 모델의 백테스트 MAPE는 돼지 재고 1.9%로 전년 동주 단순 예측 3.0%보다 낮았다.
- 소고기 수입국 HHI 약 4,100(고집중), 돼지 약 1,800. 설·추석 이후 1주 소비 지수가 소 +49%.

## 5. 과정에서 바로잡은 문제 (신뢰성)
1. **STL 과적합**: 월 재고 31개에 STL(12개월)을 적용했더니 기대값이 실제값과 거의 같아져 잔차가 0이 되었고, 돼지·소 z가 부호만 반대인 같은 직선이 나왔다. 모수가 적은 모델(추세+연 1주기)로 교체하고 회귀 테스트를 추가했다.
2. **수집 순서 오류**: 호출 한도에 걸리면 오래된 날짜부터 받아 최신 데이터를 버렸다. 최신 우선으로 수정하고, 순서를 일부러 되돌렸을 때 테스트가 실패하는 것을 확인했다.
3. **키 오류 시 한도 낭비**: 잘못된 키는 모든 호출을 실패시킨다. 인증 오류가 나면 즉시 중단하도록 했다(254건 중 4건만 호출).
4. **단위**: 돼지 재고는 톤, 소는 kg, 소비자가는 원/100g이라 모두 kg 기준으로 환산하고 테스트로 고정했다.
5. **데이터 이상**: 품질 점검이 수입 소고기 양지(냉장) 가격의 하루 +91%/−56% 급변(2026-06-17, 06-19)을 찾았다. 원본 이상인지 시세인지는 판단하지 못했다.

## 6. 한계
- 재고는 월 단위이고 약 2~3개월 지연되어 "오늘의 재고"가 아니다.
- 소 재고의 기대값은 직선 추세 기반이라 최근 급락을 크게 벗어난 것으로 계산한다(기대값 대비 약 −29%). 신호의 방향(급감)은 맞지만 크기는 부풀려졌을 수 있다. in-sample 잔차 기준이다.
- 표본이 작아 계절성·시차·예측 모두 일반화하기 어렵다. 일별 가격과 경락가는 수집이 쌓일수록 개선된다.
- 돼지 경락가는 제주만 제공되고, 소비량·도축 두수·유통 마진은 실제 데이터가 없다(`docs/METRIC_MAPPING.md`).
- 알림의 "발송 성공"은 Windows 알림 호출이 오류 없이 끝났다는 뜻이다. 집중 지원(방해 금지) 설정에 따라 화면에 표시되지 않을 수 있다. 로그와 대시보드 이력에는 항상 남는다.
