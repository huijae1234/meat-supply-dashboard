# 추가 API 조사 (Phase 3)

조사일 2026-10-08. 공공데이터포털 페이지와 검색 결과만 근거로 했고, **실제 호출로 응답을 확인한 것은 아래 "이미 연동" 항목뿐**이다.
후보 API는 활용신청과 인증키 발급(사용자 작업) 후 샘플 호출로 필드를 확인해야 한다.

## 이미 연동 (실제 호출로 확인)
| API | 제공기관 | 쓰는 곳 |
|---|---|---|
| 축산물유통정보: LPStock, consumerPriceDaily/Month | 축산물품질평가원 | 재고, 소비자가, 평년가격 |
| 축산물경락가격정보: auct/beefGrade, auct/pigJejuGrade | 축산물품질평가원 | 소 경락가, 제주 돼지 경락가 |

제외: 축산물통합이력정보(개체번호 단건 조회), AT 최근일자 도·소매가격(축산물 7건, 2019~2022 데이터).

## 후보 1 — 수입량·수입국·단가 (합성 탭 ⑤ 대체 후보)
| 항목 | 내용 |
|---|---|
| API | [관세청_신성질별 국가별 수출입실적(GW)](https://www.data.go.kr/data/15101607/openapi.do) |
| 확인한 사실 | 신성질별·국가별 수출입 통계, REST/XML, 무료, 개발계정 하루 10,000건, 활용신청 후 인증키 발급, 기간·수출입 구분·국가코드로 조회 |
| **확인하지 못한 것** | 쇠고기·돼지고기를 분리할 수 있는 분류 수준인지, 응답에 중량(kg)·금액이 모두 있는지, 월/일 단위 여부 |
| 합성 컬럼 대응(가정) | `import_volume_kg` ← 수입 중량, `country` ← 국가, `cif_price_usd_kg` ← 수입금액÷중량 (파생), `import_share_pct` ← 국가별 중량 비중 (파생) |
| 대안 | [관세청_시도별 품목별 수출입실적(GW)](https://www.data.go.kr/catalog/15101641/openapi.json) 은 HS코드 기준이며 월 1회(매월 15일경) 갱신. 시도별이라 국가별 비중은 알 수 없음 |
| 다음 단계 | 활용신청 → 샘플 호출(HS 0201·0202 쇠고기, 0203 돼지고기)로 필드 확인 → `lib/live.py` 에 수집기 추가 |

## 후보 2 — 도축 두수 (합성 탭 ③ 및 `slaughter_heads` 대체 후보)
- **API로 제공되는 도축 두수는 찾지 못했다.** 검색에서 나온 것은 사육 규모(농가 수·사육 두수) 데이터와 가축동향조사(분기 단위 사육 두수)이며, 도축 실적이 아니다.
- 가능성: 통계청 KOSIS, 축산물품질평가원 웹 통계에 월별 도축 통계가 있을 수 있으나 **이번 조사에서 OpenAPI 여부를 확인하지 못했다.**
- 다음 단계: KOSIS 통계표(도축·육류 생산 관련) 직접 검색, 없으면 탭 ③은 합성 배지를 유지.

## 후보 3 — 유통 단계 마진·리드타임 (합성 탭 ⑦)
- 공개 API를 찾지 못했다. 이 지표는 합성 데이터에서만 존재한다고 보는 게 안전하다.
- **대체 지표(이미 가능)**: 경락가(도매) → 소비자가(소매) 스프레드를 마진의 근사치로 사용. 탭 ⑨의 시차 분석과 같은 데이터. 리드타임은 대체할 수 없다.

## 추가로 활용 가능한 기존 응답 필드
- `consumerPriceDaily` 응답에는 `regionPrc1`~`regionPrc17`(지역별 소비자가)이 있는데 현재 최저·최고만 저장 중이다. 지역 코드 정의를 확인하면 지역별 가격 탭을 만들 수 있다(코드 매핑 확인 필요).
- `auct/beefGrade` 는 도매시장 코드(`abattCd`)와 성별 코드로 필터할 수 있고 한우 등급별(1++~등외) 경락가를 준다. 현재는 소계만 사용.

## 결론
| 합성 탭 | 실제 데이터 전환 가능성 |
|---|---|
| ① 현황·경보, ② 추이·예측, ⑥ 가격·소비 | 이미 실제 대응 탭이 있음 (⑧·⑨) |
| ⑤ 수입국·단가 | 관세청 API 신청·검증 후 가능성 있음 (미확인) |
| ③ 계절성·이상치(도축), ④ 명절 효과(소비량) | 소비량·도축 데이터가 API에 없음. 가격 기반 명절 효과로 대체 검토 |
| ⑦ 유통 병목 | 공개 데이터 없음. 합성 유지 |
