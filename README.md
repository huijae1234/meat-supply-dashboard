# 🥩🐷🐂 고기가 부족하게 돼지 않겠소?

**축산물(돼지·소) 수급 대시보드**

생산·재고 관리자 관점에서 **재고·가격 경보, 예측, 수입·유통 분석**을 한 화면에서 보고,
**우리 공장 CSV를 올리면 원료별 소진 예정일과 발주 지시(날짜·톤)**까지 계산하는 로컬 대시보드.
공공데이터포털 API(축산물품질평가원)로 시장 데이터를 매일 수집해 누적하고, 합성 데이터로 설계한 분석 화면을 시연용으로 함께 둔다.

> **데이터 구분이 중요하다.** 왼쪽 메뉴의 '오늘 · 우리 공장 · 실제 데이터' 그룹은 공공 API 실제 데이터와 올린 CSV, '시연 (합성 데이터)' 그룹은 설계 시연용 가짜 데이터다.
> 규모·단위·주기가 달라 섞지 않았다. 분석 결과와 한계는 [docs/ANALYSIS_NOTES.md](docs/ANALYSIS_NOTES.md) 에 있다.

## 빠른 시작 (Windows)
```
setup.bat                       # 가상환경 생성 + 패키지 설치
copy .env.example .env          # 인증키 입력 (KEY_EKAPE_DISTRIB=발급받은 Encoding 키)
.venv\Scripts\python collect.py # 실제 데이터 수집 (하루 한도 900건, 이어서 받음)
run.bat                         # 대시보드 실행 -> http://localhost:8501
```
이미 Python 환경이 있으면 `pip install -r requirements.txt` 후 `streamlit run app.py`.

## 화면 구성
**왼쪽**은 화면 이동(4개 그룹), **위쪽**은 육종(돼지/소) 선택과 `설정`(경보 민감도·기준선·데이터 다시 읽기) 팝오버다.
자주 안 바꾸는 값은 팝오버 안에 접어 두어 화면 위쪽이 복잡해지지 않게 했다.

| 화면 | 데이터 | 내용 |
|---|---|---|
| **오늘의 현황** | 실제 + 내 데이터 | 우리 공장 오늘 할 일(긴급·발주), 시장 신호(걱정 없소 / 이럼 안 돼지 / 넘쳐도 안 돼지), 쓰는 부위 시세 |
| **우리 공장** | 내 데이터(CSV) | CSV 4종 업로드·양식 내려받기, 원료별 재고일수·소진 예정·발주 기한·발주량, 지시, 예상 재고 그래프 |
| 실제 데이터 | 실제 | KPI, 부위별 재고, 소비자가·평년 대비, 국산 vs 수입, 경락가, 수집 상태·품질 |
| 실제 분석·예측 | 실제 | 재고·가격 경보, 월 재고·일 가격 예측(정확도 확인), 가격 반영 시차, 알림 이력 |
| 시연: 현황·경보 ~ 유통 병목 (7개) | 합성 | 분석 방법 시연: 경보, 추이·예측, 계절성, 명절, 수입국·단가, 가격·소비, 유통 병목 |

통계 용어(z-score, σ 등)는 실제·내 데이터 화면에서 현장 말로 풀어 씁니다("평소보다 29% 적음", "평년보다 12% 비쌈").

## 우리 공장 CSV 연결
재고·입고 예정·생산계획·배합표 4종을 올리면 원료별로 **언제 소진되는지, 언제까지 몇 톤을 발주할지**를 계산합니다.
입력 양식, 계산 규칙, 상태 기준, 알림, 접근 제한은 [docs/COMPANY_DATA.md](docs/COMPANY_DATA.md) 를 보세요.
- 처음에는 '우리 공장' 화면의 **샘플(가짜) 데이터로 시험** 버튼으로 화면과 지시 문구를 확인할 수 있습니다.
- 파일은 `data/company/`에만 저장되고 git에 올라가지 않습니다.
- **비밀번호:** `.env`에 `COMPANY_PASSWORD=...` 를 넣으면 우리 공장 부분이 잠깁니다(시장 데이터는 공개).

## 실제 데이터 수집
- **인증키**: `.env` (git 제외). 예시는 `.env.example`.
- **사용 API** (축산물품질평가원): 부위별 재고(LPStock), 일별·월별 소비자가격, 소 경락가, 제주 돼지 경락가.
  쓰지 않음: 축산물통합이력정보(개체 단건 조회), AT 최근일자 도·소매가격(축산물 7건·2019~2022).
- **호출 예산**: 개발계정 하루 1,000건 중 900건에서 멈춘다. 한도에 걸리면 **최신 날짜부터** 받고 오래된 날짜는 다음 실행에서 이어서 받는다.
- **안전장치**: 인증키·권한 오류가 나면 즉시 중단(한도 낭비 방지), 이미 받은 날짜는 건너뜀, 개별 실패는 `_errors.log` 에 기록.
- **품질 점검**: 가격 전일 대비 ±30%, 가격 없는 평일, 재고 월 누락·급변, 행 수 편차를 수집 직후 검사 → `_quality.json`, '실제 데이터' 화면에 표시.

## 자동화
```
powershell -ExecutionPolicy Bypass -File register_task.ps1     # 매일 09:00 등록
Unregister-ScheduledTask -TaskName "SupplyDashboardCollect" -Confirm:$false   # 해제
```
PC가 꺼져 있어 놓친 실행은 켜졌을 때 실행되고, 빠진 날짜는 다음 수집에서 채워진다.
로그: `data/live/collect.log`(요약), `_errors.log`(실패), `alerts.log`(경보).

## 경보 알림
수집 직후 규칙을 평가하고 **새로 생긴 경보만** Windows 알림·`alerts.log`·'실제 분석·예측' 화면 이력에 남긴다(같은 경보는 다시 보내지 않음).
| 규칙 | 기준 (기본) |
|---|---|
| 재고 | 월 재고가 평소 수준(추세+계절)에서 ±1.5 이상 벗어남, 부위별 2.5 이상 |
| 가격 | 평년 대비 ±15% 이상, 4주 연속 상승/하락 |
| 우리 공장 | 올려 둔 CSV 계산 결과가 긴급·발주 필요 (샘플은 제외) |
| 품질·수집 | 데이터 품질 경고, 마지막 수집 실패 |
```
python -m lib.alerts          # 지금 평가 + 발송
python -m lib.alerts --test   # 임계값을 낮춘 시험 (별도 이력 사용)
```
이메일은 계정 비밀번호가 필요해 넣지 않았다. 알림이 화면에 안 보이면 Windows 집중 지원 설정을 확인한다(로그·이력에는 항상 남는다).

## 데이터 한계 (요약)
- 실제 재고는 월 단위이고 약 2~3개월 지연(2024-01~2026-07). 일별 가격은 2026-04-22부터 쌓이는 중.
- 표본이 작아 예측은 **직전값 기준선을 이기지 못했다**(재고). 예측은 보조 지표로만 사용.
- 돼지 경락가는 제주 지역만 제공. 실제 소비량·도축 두수·유통 마진은 API를 찾지 못했다 → [docs/METRIC_MAPPING.md](docs/METRIC_MAPPING.md), [docs/API_SURVEY.md](docs/API_SURVEY.md).
- 우리 공장 계산은 올린 생산계획·배합표가 맞아야 정확하다. 대체 부위·국산/수입 전환, 단가·원가는 다루지 않는다.
